# 伞迹 · 3D 滑翔伞轨迹复盘（H5 / Cesium 版）

对标「径大飞行」的完整三维轨迹复盘网页：**Cesium 三维地球 + 真实卫星影像 + SRTM 级真实山体地形 + IGC/KML/GPX 解析 + 时间轴回放 + 飞行电脑式数据面板 + 高度曲线联动**。手机/电脑浏览器直接打开即可。

## 一、最快体验（30 秒）

1. 打开 `index.html`（直接双击，或本地起服务：`python -m http.server 8000` 后访问 `http://localhost:8000`）
2. 页面自动加载「泰安周边越野飞行」示例轨迹（25 分钟 / 19.5km / 3 个热气流）
3. 顶部「导入 IGC/KML/GPX」可换自己的轨迹文件

> 需要联网（Cesium 与影像瓦片走 CDN）。

## 二、达到「径大级」超清效果：免费获取 Cesium Ion Token（关键，30 秒）

不填 token 时默认用 **ESRI 免费卫星影像 + 平滑地形**（无 3D 山体）。

想获得 **Bing 高清卫星 + Cesium World Terrain（SRTM30 级真实山体起伏，就是径大那种效果）**：

1. 打开 https://ion.cesium.com 用 Google / 邮箱注册（免费）
2. 登录后首页即可看到 **Access Token**（默认 token 即可用）
3. 打开 `index.html`，把 token 粘贴到文件顶部：

```js
var ION_TOKEN = 'eyJhbGciOi...你的token'; // 第 25 行附近
```

4. 刷新页面：影像自动切换为 Bing 高清卫星，地形切换为真实 3D 山体，轨迹贴山飞行

> 免费额度：每月 5GB 流量，个人复盘完全够用。

## 四、部署（对接微信小程序 WebView）

「伞迹」小程序壳 = 一个 `<web-view src="你的H5地址">` 页面（和径大一样的架构）：

1. **部署 H5**：把本目录上传到任意静态托管（推荐腾讯云开发静态托管 / 对象存储 / GitHub Pages），必须 **HTTPS**
2. **业务域名**：微信公众平台 → 开发 → 开发管理 → 开发设置 → 业务域名，添加你的 H5 域名（需 ICP 备案、下载校验文件放置到域名根目录）
3. **小程序壳**（`pages/replay/replay.wxml` 换成）：

```xml
<web-view src="https://你的域名/index.html"></web-view>
```

4. **审核话术**（规避驳回）：首页明确声明「本应用仅用于**事后飞行复盘与教学**，不提供空中导航、实时定位功能；飞行安全请遵守民航法规」。

## 六、性能说明

- 上万点长轨迹自动抽稀至 ≤2000 点渲染，手机流畅
- 影像最大层级 18；超长越野轨迹（100km+）建议用桌面浏览器查看

## 七、二次开发

`h5-src/main.js` 是解析核心打包入口；改解析/统计后重新打包：

```bash
node -e "const esb=require('<esbuild路径>'); esb.buildSync({entryPoints:['h5-src/main.js'],bundle:true,outfile:'js/app-core.js',format:'iife'})"
```

（esbuild 可用 `npm i -D esbuild` 安装。）
